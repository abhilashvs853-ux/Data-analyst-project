Zomato Food Delivery Analysis

An Excel workbook analysing 5,000 food delivery orders across 10 Indian cities between 1 Jan 2026 and 29 Jun 2026. It covers delivery performance, revenue, customer ratings, cancellations and ordering patterns. It contains the raw data, a cleaned and feature-engineered version, pivot tables and a KPI summary.

File: zomato_edited_data.xlsx
Size: 5,000 orders × 20 raw columns (34 after feature engineering)
Tools used: Microsoft Excel (formulas, pivot tables)
